# 随译 Suiyi

Mac 全局翻译助手（原名 随译）。

一个只住在菜单栏里的个人划词翻译 / 改写工具。选中文字 → 点小圆按钮 → 翻译或改写，结果以流式方式显示在浮动卡片里。使用任何 OpenAI 兼容接口（默认 DeepSeek）。

- 无遥测；历史记录、画像自动更新和我的风格均需主动开启，首次安装默认关闭；Codex / Claude Code 接入只在点击接入按钮后执行。API Key 存在系统钥匙串（service：`ai.mars.suiyi`）。
- 不在排除列表中的应用、密码输入框、开启了“安全键盘输入”的场景中触发。

## 从 Fanyi 升级

随译首次启动时会自动迁移一次，旧数据不删除：

- 设置：从 `ai.mars.fanyi` 复制到 `ai.mars.suiyi`（已有的新设置不覆盖）。
- API Key：从钥匙串 service `ai.mars.fanyi` 复制到 `ai.mars.suiyi`。macOS 可能弹窗询问是否允许随译读取，选「允许」；拒绝则需在设置里重新填写。
- 数据：`~/.fanyi` 移动为 `~/.suiyi`，原位置留一个指向新目录的符号链接，已有引用（如 `@~/.fanyi/profile.md`）继续可用。
- Codex / Claude Code 接入：`AGENTS.md`、`CLAUDE.md` 中旧的 Fanyi 标记块会替换为随译标记块，路径改为 `~/.suiyi/profile.md`。
- 签名：未创建随译签名身份时，`build.sh` 会继续使用之前的 `Fanyi Local Signing`。

bundle id 变了，需要在 **辅助功能** 中重新授权随译。确认正常后，可手动删除旧版 `~/Applications/Fanyi.app`，并在登录项、辅助功能列表中移除 Fanyi。

## 环境

- macOS 13 及以上
- 只需 Command Line Tools（`xcode-select --install`），不需要 Xcode.app

## 构建

```bash
cd fanyi  # 仓库目录名暂未改
./build.sh
```

产物：`build/Suiyi.app`（App 图标由 `Resources/AppIcon.png` 在构建时生成 `AppIcon.icns`）（bundle id `ai.mars.suiyi`；优先使用稳定本地签名，身份不存在时回退 ad-hoc）。

## 稳定签名（避免反复授权辅助功能）

每位用户应在自己的 Mac 上创建自己的本地证书；不要共享证书或私钥。在 Mac 上运行一次：

```bash
scripts/create-signing-cert.sh
./build.sh
```

脚本会在你自己的专用钥匙串 `~/Library/Keychains/suiyi-signing.keychain-db` 中创建有效期 10 年的自签名代码签名证书 `Suiyi Local Signing`，该钥匙串的随机密码保存在你的登录钥匙串里，因此 `build.sh` 签名时不会弹出钥匙串授权框。证书和私钥文件只写入系统临时目录，脚本退出时清理，不写入仓库。（可选：`SUIYI_TRUST_CERT=1` 会把证书标记为受信任，需要输入密码；稳定授权并不需要。）首次使用新身份构建并安装后，在 **辅助功能** 中删除并重新添加 随译，最后重新授权一次。之后使用同一证书重新构建即可保留权限。

自定义身份可用 `SUIYI_SIGN_IDENTITY="你的证书名称"`（创建证书和构建均支持）；构建也兼容原来的 `SIGN_ID`，优先级低于 `SUIYI_SIGN_IDENTITY`。身份不存在时会显示警告并回退 ad-hoc，构建会打印实际使用的身份。不会启用 hardened runtime。

## 安装

```bash
./install.sh
```

会把 App 复制到 `~/Applications/Suiyi.app`（目录不存在会自动创建），结束正在运行的 随译 并重新打开。

## 授予辅助功能权限

首次启动会弹出系统提示。请打开：

**系统设置 › 隐私与安全性 › 辅助功能**，找到 随译 并打开开关。

没有这个权限就无法读取选中文字、也无法模拟 ⌘C / ⌘V。菜单里的“授予辅助功能权限…”可以随时跳转过去。授权后建议退出并重新打开一次 随译。

> 若构建回退到了 **ad-hoc 签名**：签名会随二进制变化，系统可能认为这是“另一个 App”，辅助功能开关看起来是开着但实际无效。此时请在列表里**选中 随译 点“−”删除，再点“+”重新添加** `~/Applications/Suiyi.app`，然后重启 随译。钥匙串也可能会再次询问是否允许访问 API Key，选“始终允许”即可。

## 设置 API Key

点击菜单栏图标 → **设置…**：

- **API Key**：保存到钥匙串
- **Base URL**：默认 `https://api.deepseek.com/v1`（会自动拼接 `/chat/completions`）
- **模型**：默认 `deepseek-chat`
- 任何 OpenAI 兼容服务都可以，例如 OpenAI（`https://api.openai.com/v1`）、OpenRouter（`https://openrouter.ai/api/v1`）、本地 Ollama（`http://localhost:11434/v1`）等
- **测试连接**：用当前填写的内容发一个很小的请求，显示成功或错误信息
- **目标语言**：自动（中文 → 英文，其它 → 简体中文）/ 简体中文 / English / 日本語
- **划词后显示按钮**、**开机启动**、**排除的应用**（Bundle ID，逗号分隔）

改完点 **保存**。

## 使用

- **划词**：用鼠标拖选或双击 / 三击选中文字，鼠标旁会出现一个小圆按钮。点击它或悬停片刻，会展开为 **翻译** / **改写**。4 秒不理会、点击别处或按 Esc 会自动消失。
- **快捷键**（不显示小按钮，直接出结果）：
  - `⌥⌘T` 翻译选中文字
  - `⌥⌘R` 改写选中文字（同语言给出 更简洁 / 更正式 / 更口语 三个版本）
- **结果卡片**：可拖动；**复制**、**替换**（仅当原位置可编辑时出现，会直接替换选中内容或用粘贴方式替换）、**关闭**（或 Esc / 点击卡片外部）。
- **回复**：译成中文并完成后，卡片显示对方原文和中文译文；在「我的中文回复」输入多行回复，点击 **翻译成英文** 或按 `⌘↩`（Return 换行），即可流式生成并单独复制英文回复。
- 菜单中的 **暂停划词** 只停用鼠标划词，快捷键仍可用。

翻译时会把当前应用名、窗口标题和选区附近的文字作为“背景信息”发给模型，帮助判断语境和语气（终端 / 代码、聊天、邮件、浏览器、文档）。

## 历史、画像与我的风格

在设置的 **历史与画像** 中开启或关闭「记录历史」（默认关闭，首次开启会说明数据用途并要求确认，取消保持关闭；点保存生效），查看条数、打开文件夹或确认后清空历史。仅记录成功完成的请求，排除列表中的应用、错误和提示不会记录。文件为 `~/.suiyi/history.jsonl`（权限 0600），目录权限 0700；回复记录包含对方原文、中文译文及你的中英文回复。

仅在「记录历史」开启且已配置 API Key 时，每新增 30 条记录自动生成 `~/.suiyi/profile.md`；也可以点击 **更新我的画像**。使用最近最多 200 条记录和已保存的模型配置，失败时保留旧画像。可在画像的 **我的补充** 下写个人偏好，重新生成会原样保留该部分；清空历史不会删除画像。

**接入 Codex / Claude Code** 默认不接入，启动、保存设置和生成画像均不会自动安装。只有点击该按钮才会向 `~/.codex/AGENTS.md`、`~/.claude/CLAUDE.md` 添加带随译标记的画像引用。设置了 `$CODEX_HOME` 时，Codex 使用该目录的 `AGENTS.md`（相对路径基于当前用户的主目录解析）；目标必须在当前用户主目录内，不能位于 Git 仓库中，符号链接也会校验。重复点击会更新该块；「移除接入」只移除该块，保留原有内容和文件权限。

**回复时参考我的风格** 默认关闭（需主动开启，点保存生效），只读取当前用户自己的 `~/.suiyi/profile.md`、`~/.codex/AGENTS.md`（或 `$CODEX_HOME/AGENTS.md`）和 `~/.claude/CLAUDE.md` 中的个人偏好，帮助中文回复转英文时匹配语气、长度和用词。不会用于普通翻译，也不会改变回复内容。设置会显示找到的来源。

## 隐私

历史记录、我的风格和 agent 接入均为 opt-in，默认关闭；自动画像更新随历史记录开启。所有个人数据和接入文件仅保存在各用户自己的主目录中，仓库不保存这些数据。历史与画像保存在 `~/.suiyi/`，不会自动上传，无新增服务、密钥或遥测。翻译、改写及回复仍发送到你配置的 API；画像生成也会将受长度限制的最近历史发送到同一个 API，并要求模型匿名化示例及省略秘密。开启「我的风格」时，读取到的风格背景会随回复请求发送到该 API。使用本地模型接口时，这些请求也可留在本机。

## 小提示

- 有些应用（部分浏览器、Electron 应用）不通过辅助功能提供选中文字，此时 随译 会临时模拟一次 ⌘C 读取，然后立即恢复你原来的剪贴板内容。双击选词不会使用这种方式。
- 如果 `⌥⌘T` / `⌥⌘R` 被其他应用占用，快捷键会注册失败，可以从菜单里操作。
