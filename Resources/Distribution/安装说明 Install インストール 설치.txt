随译 Suiyi — 安装说明 / Install / インストール / 설치
=========================================================

【中文】
1. 把「Suiyi.app」拖进「应用程序」文件夹，双击打开。
2. 系统提示「无法验证开发者」时：打开 系统设置 › 隐私与安全性，滚动到底部，点「仍要打开」，再确认一次。只需做一次。
3. 按提示授予辅助功能权限：系统设置 › 隐私与安全性 › 辅助功能，打开「随译」。然后退出随译再打开一次。
4. 点菜单栏的随译图标 › 设置…，填写 API Key（任意 OpenAI 兼容接口，默认 DeepSeek），点「测试连接」，再点「保存」。
5. 在设置里选「我的语言」。之后在任何 App 里选中文字，点旁边的小按钮即可翻译；⌥⌘T 翻译，⌥⌘R 改写。
如果第 2 步找不到「仍要打开」，可在「终端」运行：xattr -dr com.apple.quarantine /Applications/Suiyi.app

【English】
1. Drag "Suiyi.app" into your Applications folder and open it.
2. If macOS says the developer cannot be verified: open System Settings › Privacy & Security, scroll to the bottom, click "Open Anyway" and confirm. You only need to do this once.
3. Grant Accessibility access when asked: System Settings › Privacy & Security › Accessibility, turn on Suiyi. Then quit and reopen Suiyi.
4. Click the Suiyi icon in the menu bar › Settings…, enter an API key (any OpenAI-compatible API; DeepSeek by default), click Test Connection, then Save.
5. Pick "My language" in Settings. Then select text in any app and click the small button to translate; ⌥⌘T translates, ⌥⌘R rewrites.
If you can't find "Open Anyway" in step 2, run this in Terminal: xattr -dr com.apple.quarantine /Applications/Suiyi.app

【日本語】
1. 「Suiyi.app」を「アプリケーション」フォルダにドラッグして開きます。
2. 「開発元を検証できません」と表示されたら：システム設定 › プライバシーとセキュリティ を開き、一番下の「このまま開く」をクリックして確認します。最初の一回だけです。
3. 案内に従ってアクセシビリティを許可します：システム設定 › プライバシーとセキュリティ › アクセシビリティ で Suiyi をオンにし、Suiyi をいったん終了してもう一度開きます。
4. メニューバーの Suiyi アイコン › 設定… で API キーを入力し（OpenAI 互換の API。既定は DeepSeek）、「接続テスト」のあと「保存」をクリックします。
5. 設定で「自分の言語」を選びます。あとはどのアプリでもテキストを選択し、横の小さなボタンで翻訳できます。⌥⌘T で翻訳、⌥⌘R で書き換え。
手順 2 で「このまま開く」が見つからない場合は、ターミナルで次を実行してください：xattr -dr com.apple.quarantine /Applications/Suiyi.app

【한국어】
1. 「Suiyi.app」을 「응용 프로그램」 폴더로 드래그한 뒤 엽니다.
2. "개발자를 확인할 수 없습니다"라는 메시지가 나오면: 시스템 설정 › 개인정보 보호 및 보안을 열고 맨 아래에서 「그래도 열기」를 클릭한 뒤 확인합니다. 처음 한 번만 하면 됩니다.
3. 안내에 따라 손쉬운 사용 권한을 허용합니다: 시스템 설정 › 개인정보 보호 및 보안 › 손쉬운 사용에서 Suiyi를 켜고, Suiyi를 종료했다가 다시 엽니다.
4. 메뉴 막대의 Suiyi 아이콘 › 설정…에서 API 키를 입력하고(OpenAI 호환 API, 기본값 DeepSeek) 「연결 테스트」 후 「저장」을 클릭합니다.
5. 설정에서 「내 언어」를 선택합니다. 이후 어떤 앱에서든 텍스트를 선택하고 옆의 작은 버튼을 누르면 번역됩니다. ⌥⌘T는 번역, ⌥⌘R은 다시 쓰기입니다.
2단계에서 「그래도 열기」가 보이지 않으면 터미널에서 다음을 실행하세요: xattr -dr com.apple.quarantine /Applications/Suiyi.app
